# Gate the two non-code repos, `~/vault/givore` and givore.com — plan

## Task

Give `~/vault/givore` a commit gate that lints the documents a commit changes, and givore.com a push
gate that builds the Hugo site, both set up by the operator with `qg init --profile`. Add a built-in
`doc-lint` driver that counts only findings a commit adds and ignores the environment switches that
silence doc-lint. Make `qg init` protect the gate files by exact path. Rewrite the two Givore
indications on the gate to name `qg`.

Keywords: `doc-lint`, `drivers/doc-lint.sh`, `guard_doc_lint`, `qg init --profile docs`,
`templates/init/docs.tsv`, `templates/init/hugo.tsv`, `guard_protected_paths`, `lines=added`,
`DOC_LINT`, `DOC_LINT_SKIP`, `DOC_LINT_PATTERNS`, `.doc-lint`.

**Priority when two qualities conflict:** no hidden bypass first, then a gate that refuses only what
the commit added, then less code.

## Decisions

| decision | reason | record |
|----------|--------|--------|
| The docs profile's `doc-lint` row uses a built-in `doc-lint` driver, not a shell row | a shell row inherits the caller's `DOC_LINT*` and `VAULT_FRAMEWORK_PATH` and lints whole files | local |
| The driver counts line findings on added lines through `qg_added_only`, and a file-level finding only on a file absent at `QG_BASE` | old findings in shared files would refuse most commits | local |
| The linter path comes from `guard_doc_lint` in `quality/config` at `QG_CONFIG_REV`, an absolute path; `qg init --profile docs` writes it from `VAULT_FRAMEWORK_PATH`, else `$HOME/workspace/vault/bin/doc-lint.sh` | a commit cannot repoint the linter that judges it | local |
| `qg init` protects `quality/checks.tsv quality/baseline.tsv quality/rules.tsv quality/config quality/drivers`, plus `.doc-lint` for the docs profile | a `quality/` prefix protects unrelated files; `.doc-lint` suppresses codes | local |
| `templates/init/hugo.tsv` stays as written | its row builds in 4.4 s with the CI hugo version | local |
| S5 is built in worktree `~/workspace/vault-quality-gates-s5`, branch `feat/qg-docs-repos` from `main` `3f43b43` | the live gate runs from `main`'s working tree | local |

## Rollback

Before the operator's init commits, `git revert` of the merge on `main` removes the driver. After
them, a repo returns to ungated with `qg hooks remove` and a commit deleting `quality/checks.tsv`
under `qg override`. The indication commit in `~/vault/givore` reverts on its own.

## Test plan

tests use the fixture linter of W-2; one case runs the real framework doc-lint when it is present
and skips otherwise. SC-3 and SC-4 run on scratch clones of the live repos.
