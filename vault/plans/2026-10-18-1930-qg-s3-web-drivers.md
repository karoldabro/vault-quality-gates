# Web drivers and the app.givore.com and dashboard.givore.com v2 migrations — plan

## Task

Give the gate eight built-in web drivers (`eslint`, `nuxt-typecheck`, `knip`, `depcruise`, `fallow`,
`vitest`, `stryker`, `jscpd`), extend `jscpd-added`, add one node runner shared by both Nuxt repos,
and close the host pnpm registry hole S2 left, recycling-api's prepared rows included. Prepare
app.givore.com's 21 and dashboard.givore.com's 13 gate rows in the v2 format with a row-parity proof
each, and prove every v2 row measures on each repo's `master` and `development` merged with the
migrated release branch. All code lands in worktree `~/workspace/vault-quality-gates-s3`, branch
`feat/qg-web-drivers`. Repo files are prepared under `migrations/app.givore.com/`,
`migrations/dashboard.givore.com/` and `migrations/web/`; the operator copies them and commits.

Keywords: `drivers/eslint.sh`, `drivers/nuxt-typecheck.sh`, `drivers/knip.sh`, `drivers/depcruise.sh`,
`drivers/fallow.sh`, `drivers/vitest.sh`, `drivers/stryker.sh`, `drivers/jscpd.sh`,
`drivers/jscpd-added.sh`, `qg_pnpm_isolated`, `qg_jscpd_report`, `qg_clover_percent`, `in-node.sh`,
`qg-parity-app.givore.com.sh`, `qg-parity-dashboard.givore.com.sh`.

**Priority when two qualities conflict:** no new bypass first, then a row's verdict unchanged by the
migration, then less code.

## Rollback

Every change to this repo reverts with `git revert` on `main` while no repo has committed its v2
config. After a migration commit, revert that repo's migration commit first, with `qg override`, while
S3 is still on `main`, then revert S3: the S2 engine refuses the new drivers as unknown. This holds
for recycling-api too once its `duplication` rows name driver `jscpd`.

## Test plan

Bats unit tests in `tests/unit/`, run by `./tests/run.sh tests/unit` (image `tests/Dockerfile`). Each
driver test feeds recorded tool output and real exit codes through a fake `node_modules/.bin/<tool>`
and a fake runner that records its argv, then compares `metric` with the v1 computation on the same
output, run by `node` where v1 is a node script. End to end: the three parity scripts on scratch clones
with the real tools. Every `checks/` script runs through `gate.sh verdict --run`, never directly: the
agent hook refuses a script that writes to computed paths.
