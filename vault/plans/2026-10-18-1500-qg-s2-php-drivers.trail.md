## Decisions & trade-offs

| decision | alternative rejected | why it lost |
|---|---|---|
| Prepare recycling-api files under `migrations/recycling-api/` | edit a recycling-api worktree | the edit guard denies `quality/config` in every repo |
| Shared driver kit in `lib/` | copy `kv`/`extra` into each driver | nine copies; the contract's self-contained example stays for repo drivers |
| `in-server.sh` runner for release rows | reuse `in-tree.sh` | it extracts HEAD rule code over its tree, which is the working tree on push |
| Compose run on `<tree>`, as `7add7c29`, for release rows | `docker compose exec` plus a main-checkout refusal | refuses every release push from 13 linked worktrees |
| Per-run report cache | cache keyed by target commit | outlives the run, keys on `HEAD` under baseline, ignores untracked files |
| pint counts files and takes new ids | `min(files,1)` keeps the ids | a count tells the fixer how much is left; diff rows need no baseline |
| Seeded report for whole-suite rows | live 57-minute suite per side | cost; the driver reads the same report the parser reads |
