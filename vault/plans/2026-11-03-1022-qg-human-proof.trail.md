## Decisions & trade-offs

| decision | alternative rejected | why it lost |
|---|---|---|
| sudo password proves the human | stop the parent walk at WSL's root-owned `Relay(N)` | `setsid -f env -i script` already passes the walk, and a WSL agent can open a clean session through `wsl.exe`; the operator chose the password |
| sudo password proves the human | allow-list of terminal programs at the top of the walk | an agent can launch a real terminal binary or a hidden Windows launcher; uncommon terminals refused |
| stop the walk at WSL's `Relay(<n>)`, deny wrappers in `guard_bash.py` | sudo password proof with a root-owned grant | the engine code and each repo's `.git/hooks` are user-writable, so an agent edits the check instead; the password becomes a root credential typed into hooks |
| stop the walk at WSL's `Relay(<n>)`, deny wrappers in `guard_bash.py` | root-owned engine install | each repo's hook file and `core.hooksPath` stay user-writable; scope doubles; updates need sudo |
