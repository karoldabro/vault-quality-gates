# qg-guard-scope — process record

## Seating
No persona pack resolves for this repo (bash and Python, no stack marker). The panel seats `planning/harness-engineer` as architect, `security`, `correctness` and `consumer`. `security` raises the cap to 4 because the change narrows an agent permission guard.

## Research
- hk's agent stop hook passes in repos without hk config, which makes a user-level install safe (`vault/research/2026-10-18-gate-tools-survey.md:63`).
- Claude Code passes `cwd` in every hook event, so a user-level hook can scope itself without per-repo settings.

## Rejected alternatives
- Per-repo install in each gated repo's `.claude/settings.json`: a session started outside a gated repo could then commit there with `--no-verify` unchecked. The operator chose the scoped user-level install.
- Gated as "configured" (`VAULT.md` names the plugin, or `quality/` files at HEAD): it keeps agent-control guarded with no hook to protect. The operator chose "hook installed".
