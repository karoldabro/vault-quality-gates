## Research

- landrun wraps Landlock for unprivileged sandboxing of any command; filesystem rules need kernel
  5.13+, network rules ABI 5 (https://pkg.go.dev/github.com/zouuup/landrun@v0.1.12). Not installed
  here; the plan uses the same syscalls from Python stdlib.
- Ubuntu 24.04 restricts unprivileged user namespaces through AppArmor, which is why bwrap fails
  with `setting up uid map: Permission denied`; the fixes need root
  (https://etbe.coker.com.au/2024/04/24/ubuntu-24-04-bubblewrap/).
- Claude Code reads hooks from user settings `~/.claude/settings.json` for every project, beside
  project and managed settings (https://docs.anthropic.com/en/docs/claude-code/settings).
