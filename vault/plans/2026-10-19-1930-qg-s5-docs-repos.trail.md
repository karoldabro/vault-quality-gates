## Research

- Changed-line lint filtering is the common answer to legacy findings: reviewdog reports only issues
  in the diff by default (https://x-cmd.com/install/reviewdog); graylint keeps only messages caused
  by recent changes (https://github.com/akaihola/graylint); git-lint reports only added or modified
  lines (https://pypi.org/project/git-lint/0.0.3/). The plan follows it with the kit's existing
  `qg_added_only`.
